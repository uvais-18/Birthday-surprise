# 🎂 Birthday Surprise 🎉

A small birthday website I made to make someone's special day a little more memorable ❤️

It is built using **HTML, CSS, and JavaScript** and includes simple animations, birthday wishes, and a few fun surprises.

You can easily customize the text, colors, images, and messages to create your own birthday surprise for someone special.

---

## 🎁 Features

- 💌 Personalized birthday wishes
- ✨ Smooth animations and effects
- ⌨️ Typewriter-style message effect
- 📱 Works on both mobile and desktop
- ❤️ Simple and easy to customize
- 🎉 A fun way to send a birthday surprise online

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 🚀 How to Use

Clone the repository:

```bash
git clone https://github.com/uvais-18/Birthday-surprise.git
```

Move into the project folder:

```bash
cd Birthday-surprise
```

Then open `index.html` in your browser.

You can edit the HTML, CSS, and JavaScript files to add your own messages, photos, colors, and birthday wishes.
